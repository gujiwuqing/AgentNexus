# 编码规范（Coding Standards）

> 用途：团队通用的编码基线，语言无关的原则 + 常见语言约定。目标是让**任何人写出的代码看起来像同一个人写的**，降低维护与协作成本。
> 使用建议：挂载给「代码评审员」「技术方案师」Agent，作为判断"是否符合规范"的依据。

## 一、通用原则

1. **可读性优先于聪明**。代码被阅读的次数远多于被编写的次数。
2. **一致性优先于个人偏好**。进入一个模块，先遵循它已有的风格，不自创模式。
3. **显式优于隐式**。不要依赖隐藏的副作用、全局状态、魔法约定。
4. **小步单一职责**。函数做一件事，模块有清晰边界，改动可局部化。
5. **让非法状态不可表示**。用类型/枚举/约束把错误挡在编译期或入口。

## 二、命名

- 命名表意，避免缩写歧义（`cnt` → `count`，`usr` → `user`）。
- 布尔量用 `is/has/can/should` 前缀（`isActive`、`hasPermission`）。
- 函数名用动词短语（`fetchUser`、`calculateTotal`），返回集合用复数。
- 常量全大写下划线；避免"魔法值"直接出现在逻辑里。
- 避免类型冗余后缀（`userData`、`userInfo`、`userObj` 通常都该叫 `user`）。

## 三、函数与控制流

- 单函数建议不超过一屏（约 50 行）；圈复杂度过高应拆分。
- **早返回**减少嵌套：先处理边界/错误并 return，主逻辑保持在最外层。
- 参数超过 3~4 个时，用对象/结构体传参，提升可读性与向后兼容。
- 避免布尔标志参数控制两种行为（`doThing(true)`）——拆成两个函数。
- 不用输出参数表达返回值；一个函数只有一个清晰的返回契约。

## 四、错误处理

- 不吞异常：至少记录足够上下文的日志或向上传播。
- 错误信息包含"发生了什么 + 关键上下文（不含敏感信息）"，便于排查。
- 区分**预期内的业务错误**（返回结构化错误码）与**预期外的异常**（记录告警）。
- 资源（连接、文件、锁）确保释放（`defer`/`finally`/`using`/`try-with-resources`）。
- 不用异常控制正常流程。

## 五、注释与文档

- 注释解释**为什么**（权衡、坑、业务背景），而非复述代码在做什么。
- 公共 API/复杂算法/非直觉决策必须有说明。
- 代码即将删除的临时逻辑标注 `TODO(owner, date, reason)`，可追溯。
- 过时注释比没有注释更糟——改代码时同步改注释。

## 六、日志

- 分级使用：`debug`（排查）、`info`（关键业务节点）、`warn`（可恢复异常）、`error`（需人工关注）。
- 结构化日志（键值对）优于拼接字符串，便于检索与告警。
- **绝不打印**：密码、token、密钥、完整身份证/银行卡、原始请求体中的隐私字段。
- 热路径避免高频日志导致性能与存储问题。

## 七、依赖与配置

- 新增依赖需评估：是否必要、维护活跃度、许可证、体积、安全记录。
- 配置与代码分离，通过环境变量/配置中心注入；不硬编码环境相关值。
- 密钥只从安全来源读取，绝不进代码库。

## 八、语言相关约定（摘要）

### 通用格式
- 使用团队统一的格式化工具（Prettier / gofmt / black / spotless 等），格式化不进入人工评审讨论。
- 提交前自动跑 Lint + Format，保持 diff 干净。

### JavaScript / TypeScript
- 开启 `strict`；避免 `any`，用 `unknown` + 收窄。
- 优先 `const`；不可变数据优先；异步统一用 `async/await` 并处理 rejection。
- 模块边界导出明确类型；避免默认导出带来的重命名混乱（按团队约定）。

### Java / Kotlin
- 遵循分层与包结构约定；避免在实体里塞业务逻辑。
- 空安全：优先 `Optional`/可空类型标注，边界处校验。

### Go
- 错误显式处理，不忽略 `err`；用 `errors.Is/As` 判断；`context` 贯穿调用链。
- 小接口、组合优于继承；导出符号有文档注释。

### Python
- 类型标注 + `mypy`；遵循 PEP8；避免可变默认参数。

## 九、提交前自检（Definition of Done 片段）

- [ ] 命名清晰、无死代码、无调试打印。
- [ ] 边界与错误路径已处理。
- [ ] 通过格式化、Lint、编译、单测。
- [ ] 无敏感信息泄漏。
- [ ] 必要的文档/注释已更新。
